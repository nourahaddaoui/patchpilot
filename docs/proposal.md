# Proposal — PatchPilot (Project 3: The Operator)

PatchPilot is a vulnerability remediation agent for Python repositories: it scans a repo with Trivy, picks a fix (a dependency bump in `requirements.txt`), runs the tests inside a sandbox container, and commits the fix to a sandbox branch only after a human approves the diff. It uses four tools, of which only one writes: `run_scan` (read), `read_file` (read, allowlisted paths), `run_tests` (read, in the container) and `edit_file` (write, idempotent, approval required, `requirements.txt` only). A stop rule written before any agent code ends every run on the first of: approval denied, no fixed version exists, done (scan clean and tests green), 3 failed fix attempts, a $0.50 cost cap, or 12 steps. We will evaluate it on 30+ scenarios (fix cases, fault-injected tool failures, prompt-injection attempts and human-in-the-loop cases), each with expected steps and an expected stop reason, graded in plain code on step accuracy, tool-call precision, wasted steps, task success, recovery rate and "no write before approval", and we will report cost per task, p50/p95 latency and projected cost at 100x volume.
